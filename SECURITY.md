# Security policy

## Supported versions

Until the first stable release, only the latest commit on `main` receives security fixes.

## Reporting a vulnerability

Please use GitHub's **Private vulnerability reporting** feature instead of a public issue. Include affected versions, impact, reproduction steps using harmless artifacts, and a proposed mitigation if available.

Do not attach live malware or sensitive user data. Maintainers should acknowledge a report within seven days and coordinate disclosure after a fix is available.

## Operational warning

Aegis Guard is experimental and is not a replacement for Microsoft Defender or another supported endpoint security product. Do not disable existing protection to test this project.
